# 30 & FABULOUS — подключение RSVP к Supabase

Этот архив собран на основе актуального GitHub ZIP, который вы прислали. Текущие HTML, CSS, JavaScript, изображения, тексты, расписание и генератор образов сохранены. Добавлена отправка RSVP в Supabase.

## 1. Создайте таблицу

1. Откройте Supabase Dashboard → SQL Editor → New query.
2. Скопируйте весь файл `supabase-setup.sql`.
3. Нажмите Run.

Таблица `public.guests` хранит:
- `name` — имя;
- `contact` — Telegram или телефон;
- `attendance` — `yes`, `part` или `no`;
- `drink` — выбранный напиток;
- `note` — комментарий;
- `created_at` — дата и время отправки (ставит база данных).

Политика RLS разрешает посетителям сайта только INSERT. Публичное чтение списка гостей закрыто.

## 2. Вставьте ключи проекта

В Supabase откройте Project Settings → API (или Connect / API Keys):
- Project URL;
- Publishable key (предпочтительно) или legacy `anon` key.

Откройте `supabase-config.js` и замени значения:
```js
window.SUPABASE_CONFIG = {
  url: 'https://ВАШ-ПРОЕКТ.supabase.co',
  anonKey: 'ВАШ_PUBLISHABLE_KEY'
};
```

На сайт можно помещать только Publishable/anon key. Никогда не публикуйте Secret key или `service_role`.

## 3. Опубликуйте на GitHub Pages

Загрузите содержимое архива в корень репозитория, сохранив папку `img/`. В частности, добавьте `supabase-config.js` и `supabase-setup.sql`; замените актуальные `index.html` и `script.js`. После Commit changes дождитесь обновления GitHub Pages.

## 4. Проверьте

Откройте сайт, заполните RSVP тестовыми данными и отправьте форму. В Supabase откройте Table Editor → `guests`: новая строка должна появиться там.

Если отправка не удалась, форма останется открытой и покажет ошибку — сайт не будет ошибочно сообщать, что ответ сохранён.

## Важно

- Не включайте публичные SELECT-политики: список гостей содержит личные контакты.
- В Supabase Table Editor вы сможете просматривать ответы после входа в свой аккаунт.
- Поскольку публичная форма доступна всем посетителям, для реального публичного запуска рекомендуется добавить CAPTCHA / антиспам-защиту и лимиты запросов.
